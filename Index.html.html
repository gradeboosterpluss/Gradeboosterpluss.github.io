How to Host on GitHub Pages

  1. Create a repository on GitHub named grade-booster-plus.
  2. Save this code file as index.html and upload it to your repo.
  3. Go to Settings → Pages tab in your GitHub repository.
  4. Select Branch: main (or master) and folder / (root), then click Save.
  5. Your site will be live within 1–2 minutes!
